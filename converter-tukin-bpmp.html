Privasi: file Excel diproses lokal di browser dan tidak dikirim ke server.

Kode objek pajak ditetapkan otomatis sebagai 21-100-01. Status pegawai = Resident.

Aturan: bila PPh Satker = PPh TER, fasilitas XML = N/A dan tarif XML = tarif TER. Bila berbeda, fasilitas XML = ECT. Karena Coretax membatasi tarif maksimal 2 angka desimal, aplikasi memilih tarif 2 desimal yang menghasilkan PPh paling dekat dengan PPh Satker dan menampilkan sisa selisihnya.
