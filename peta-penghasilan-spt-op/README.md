# Peta Penghasilan SPT OP · Kabayan

Paket statis siap unggah ke GitHub Pages.

## Cara mengunggah

1. Ekstrak file ZIP.
2. Unggah seluruh isi folder `peta-penghasilan-spt-op` ke repository GitHub.
3. Pastikan `index.html`, folder `assets`, dan folder `data` berada pada tingkat yang sama.
4. Aktifkan GitHub Pages dari branch dan folder tempat file diunggah.

Tidak memerlukan proses build, database, atau pengaturan variabel lingkungan.
