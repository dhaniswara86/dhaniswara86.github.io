<section id="pengantar">
<p>
Lupa kata sandi dapat membuat pengguna tidak dapat masuk ke <strong>Coretax DJP</strong>. Namun, kondisi ini tidak berarti Wajib Pajak harus membuat akun baru. Pada halaman login Coretax tersedia fasilitas <strong>Lupa Kata Sandi?</strong> untuk melakukan pengaturan ulang kata sandi.
</p>

<p>
Berbeda dengan DJP Online sebelumnya, pengaturan ulang kata sandi di Coretax <strong>tidak membutuhkan EFIN (Electronic Filling Identification Number)</strong>. Tautan untuk membuat kata sandi baru dapat dikirimkan melalui alamat email atau nomor gawai yang terdaftar.
</p>

<div class="lp-callout lp-callout-blue">
  <div class="lp-callout-icon" aria-hidden="true">
    <svg viewBox="0 0 24 24" role="img">
      <path d="M7.5 10V7.5a4.5 4.5 0 0 1 9 0V10M6 10h12a1.5 1.5 0 0 1 1.5 1.5v7A1.5 1.5 0 0 1 18 20H6a1.5 1.5 0 0 1-1.5-1.5v-7A1.5 1.5 0 0 1 6 10Zm6 4v2.5"/>
    </svg>
  </div>
  <div>
    <strong>Intinya</strong>
    <p>Jika akun sudah ada tetapi Anda lupa password, gunakan fasilitas "Lupa Kata Sandi". Jangan membuat akun baru hanya karena tidak mengingat password.</p>
  </div>
</div>
</section>
