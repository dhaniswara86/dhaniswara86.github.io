Yang divalidasi Kabayan

  • NPWP Pemotong wajib terdiri dari 16 digit.
  • Masa pajak 1–11 dan tahun pajak terisi.
  • Status Penerima: Dalam Negeri atau Luar Negeri. Kabayan mengubahnya otomatis menjadi Resident/Foreign pada XML.
  • Status PTKP sesuai daftar BPMP.
  • Kode objek pajak terisi.
  • Penghasilan bruto lebih dari nol.
  • ID TKU Pemotong wajib terdiri dari 22 digit.
  • Pada Template Kabayan, Tanggal Pemotongan wajib menggunakan format dd-mm-yyyy; saat XML dibuat Kabayan mengubahnya menjadi yyyy-mm-dd.
  • Tarif TER tidak perlu diisi pada Template Kabayan; Kabayan menghitungnya otomatis dari Status PTKP dan Penghasilan Bruto.

Struktur XML

  • Root: MmPayrollBulk.
  • NPWP Pemotong: TIN.
  • Setiap baris: MmPayroll.
  • Urutan elemen mengikuti XML Map yang tertanam pada BPMP v.3.
  • Untuk fasilitas ETC, Kabayan mempertahankan literal sebagaimana referensi DATA pada workbook DJP.
  • Data tidak dikirim ke server Kabayan; proses terjadi pada browser pengguna.

Struktur yang dibaca

  • Root XML: A1Bulk.
  • NPWP Pemotong: TIN.
  • Setiap record: A1.
  • Gross-Up menggunakan field GrossUpOpt dari template.
  • Urutan elemen mengikuti XML Map yang tertanam dalam workbook BPA1.

Validasi minimum Kabayan

  • NPWP Pemotong 15–16 digit.
  • Masa awal/akhir 1–12 dan masa awal tidak melebihi masa akhir.
  • NIK/TIN penerima, PTKP, status bukti potong, objek pajak, dan ID TKU.
  • Resident/Foreign serta paspor untuk penerima asing.
  • Opsi Gross Up hanya Yes/No.
  • Tanggal pemotongan dapat dibaca.
